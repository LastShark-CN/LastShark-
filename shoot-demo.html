Shoot Demo

一款简单的射击小游戏。玩法直白：移动、瞄准、开火，把屏幕上出现的目标清掉。目前还是半成品——版本号停在 0.1.1-alpha，关卡、数值和手感都只做到了能跑通的程度， bug 和空缺的玩法都不少。

它最早是我用来练手引擎和地形渲染的小项目，包里的 libterrain.windows.debug.x86_64.dll 就是那份地形库的调试构建。所以你会在游戏里看到一些和射击本身关系不大的地形测试痕迹，那是它的来历，不是 bug（好吧，也有一部分是 bug）。

放出来不是为了让你夸它完成度高，而是想留个存档：看看一个半成品长什么样，也欢迎你告诉我哪里手感不对。后续如果继续做，会在这里更新进度。

怎么玩

  1. 把 32 个分卷全部下载到同一个文件夹，文件名不要改。
  2. 用 7-Zip 或 Bandizip 打开 Shoot Demo.zip.001，选"解压到当前文件夹"，会自动合并所有分卷。
  3. 进入解出的 Shoot Demo 文件夹，双击 Shoot Demo 0.1.1-alpha.exe 运行。
  4. 首次运行若被 Windows Defender 或 SmartScreen 拦截，属正常现象（未签名程序），确认来源后可选择"仍要运行"。
提醒：这是未签名的个人作品，杀毒软件可能误报；下载请只认本页链接。游戏为 alpha 阶段，存档、分辨率选项和部分按键映射尚未实现，遇到闪退属于预期内行为。
